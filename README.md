# hydro 题库

本仓库只收录官方数据，不收录民间数据，hack 数据。题面部分来自 luogu。

如果你没有为本仓库做贡献的想法，请**不要** clone 这个仓库！可以直接点击下方下载链接下载并上传到 Hydro 使用。由于git lfs 10GB的文件限额，本仓库使用 github releases 分发文件。

如果你想对这个仓库做贡献，但不想 clone 几个 GB 的仓库，可联系 QQ 1823773407 或 [邮件](mailto:admin@vblg.top)，备注来意并发送题目和数据给我。或者你也可以开一个 issue 并提交文件，我看到后会审核并合并。
