# 题目背景

启发来自以下数学题：

> 设 $n$ 是不小于 $3$ 的正整数，集合 $S_n=\{(a_1,a_2,\dots,a_n)\, a_i \in \{0,1\},i=1,2,\dots n\}$，对于集合 $S_n$ 中的任一两个元素 $a=(a_1,a_2,\dots,a_n), B= (b_1,b_2,\dots,b_n)$，定义 $A*B=n-(|a_1-b_1|+|a_2-b_2|+\dots+|a_n-b_n|)$。若 $A*B=0$，则记 $A=\overline B,B=\overline A$。
>
> 1. 若 $n=3,A=(0,1,0),B=(1,1,0)$ 写出 $\overline A,\overline B,A*B$。
> 2. 若 $A,B\in S_n$，证明 $A*B+\overline A*B=n$
> 3. 设 $k$ 是小于 $n$ 的正奇数，对于至少含有两个元素的 $S_n$ 的子集，满足 $\forall A,B,A\neq B$，均有 $A*B=n-k$。求 $M$ 的元素个数的所有可能取值。

小 A 正在研究长度为 $n$ 的二进制串。他发现，两个串的“相似度”可以用它们相同位置的个数来衡量。

# 题目描述

设 $n$ 是不小于 $3$ 的正整数，集合
$$
S_n=\{(a_1,a_2,\dots,a_n)\mid a_i\in\{0,1\},\ i=1,2,\dots,n\}.
$$
对于 $A=(a_1,\dots,a_n),B=(b_1,\dots,b_n)\in S_n$，定义
$$
A*B=n-\big(|a_1-b_1|+|a_2-b_2|+\cdots+|a_n-b_n|\big).
$$
也就是说，$A*B$ 等于两个串对应位置相同的个数。

给定 $n,k,m$，其中 $k$ 是小于 $n$ 的正奇数。求从 $S_n$ 中选出 $m$ 个互不相同的元素组成集合 $M$，使得对于任意 $A,B\in M,\ A\ne B$，都有
$$
A*B=n-k
$$
的方案数。

答案对 $998244353$ 取模。

# 输入格式

一行三个整数 $n,k,m$。

# 输出格式

一个整数，表示方案数对 $998244353$ 取模的结果。

# 样例 #1

## 样例输入 #1

```text
3 1 2
```

## 样例输出 #1

```text
12
```

## 样例解释 #1

长度为 $3$ 的二进制串共有 $8$ 个。要求两串相似度为 $3-1=2$，即汉明距离为 $1$。  
距离为 $1$ 的无序对数量为
$$
2^{3-1}\times \binom{3}{1}=4\times 3=12.
$$

# 样例 #2

## 样例输入 #2

```text
3 1 3
```

## 样例输出 #2

```text
0
```

# 数据范围

- $3\le n\le 10^6$
- $1\le k<n$，且 $k$ 为奇数
- $2\le m\le 10^5$
